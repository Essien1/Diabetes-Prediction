# 📊 Diabetes Prediction Using BRFSS Data

This project builds an end-to-end machine learning pipeline to predict diabetes risk using the 2024 BRFSS dataset. It focuses on early detection using survey-based health and lifestyle data.

---

## 🚀 Overview

Diabetes is a major public health issue, and many cases go undiagnosed.  
This project uses machine learning to identify individuals at risk based on non-clinical data.

Key steps include:
- Data cleaning and preprocessing
- Handling survey-coded missing values
- Feature engineering and selection
- Class imbalance handling (SMOTE)
- Model training and evaluation

---

## 🧠 Models Used

- Logistic Regression  
- Random Forest  
- XGBoost  

All models were tuned using GridSearchCV.

---

## 📊 Evaluation Metrics

The models were evaluated using:

- Accuracy  
- Precision  
- Recall (primary metric)
